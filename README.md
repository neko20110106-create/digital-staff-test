# デジタルスタフ

**バージョン：v1.0.0（正式版）**

手動操作型のデジタルスタフWebアプリです。v1.0.0では、基本的なスタフ編集・運転操作・データ保存機能を正式版として公開しています。スマートフォン・タブレット・PCのブラウザで利用できます。駅時刻や停車・通過情報を設定し、運転画面で駅の進行を手動操作できます。

## アプリ

- **リンク:** https://neko20110106-create.github.io/digital-staff/settings.html

※基本的にはタブレットの縦画面推奨です。

## 基本的な使い方

1. 「設定・スタフ編集」で列車番号・種別・行先・路線・両数を入力します。
2. 駅名、着時刻、発時刻、停車・通過、徐行、保安装置の切り替え情報を登録します。
3. 必要に応じて遅延時間、運転画面に表示する駅数、アニメーションを設定します。
4. 「運転開始」を押すと運転画面に移動します。
5. 運転画面ではボタンを使って駅の進行を手動操作します。終点到着後は運転を終了できます。

## 主な機能

### 列車・駅情報
- 列車番号、種別、行先、路線・方向、両数の設定
- 駅名、着時刻、発時刻、停車・通過の登録・編集・削除
- 徐行区間と制限速度の設定
- 保安装置の切り替え情報の表示

### 運転画面
- 現在地・次駅と駅時刻の表示
- 駅の進行を手動で操作
- 遅延時間を反映した着発時刻の表示
- 表示する駅数を2～20駅の範囲で設定
- 運転画面上部から表示駅数を変更
- リセットと運転終了（終了前に確認を表示）
- スマートフォン・タブレットの画面幅や向きに応じたレイアウト

### アニメーション
- 駅名切り替え時のフェード
- 発車時・停車時の枠の発光
- 経過時間の数字切り替え
- ページ切り替え時のアニメーション
- アニメーション全体のON/OFFと、各アニメーション個別のON/OFF

### 複数スタフ管理
- 名前を付けて複数のスタフをブラウザ内に保存
- 保存済みスタフの読み込み・削除
- 列車情報、駅データ、遅延設定、表示駅数をスタフごとに保存

### データの保存・移行
- 設定データのブラウザ内保存
- JSON形式での書き出し・読み込み
- CSV形式での駅データ書き出し・読み込み
- Excelで編集できるCSVテンプレートの保存

## データとプライバシー

- 入力した列車情報や駅データは、利用しているブラウザのローカルストレージに保存されます。
- 表示設定、アニメーション設定、遅延設定、運転状態などもブラウザ内に保存されます。
- このアプリ自体は、入力データを開発者のサーバーへ送信する機能を備えていません。
- 保存データは同じブラウザ内で利用するもので、端末間で自動同期されません。
- ブラウザのデータ削除やプライベートブラウズの利用などにより、保存内容が消える場合があります。必要に応じてJSONやCSVでバックアップしてください。
- 個人情報や他人に知られたくない情報は入力しないでください。

## 重要な注意

本アプリは個人制作の趣味・シミュレーション用ツールです。実在の鉄道会社・鉄道事業者とは関係ありません。表示される列車情報・駅名・時刻はサンプルまたは利用者が入力したものであり、実際の運行情報を示すものではありません。

**実際の鉄道運行、乗務、運転取扱い、保安装置の代用には絶対に使用しないでください。**
